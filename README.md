This repository contains the scripts used in Karwat et al.

Each script and its purpose are described below:

R1_corr_calc.R : Computes correlation, p-values, Rsquared, MAE, and RMSE from two data sets (e.g., NOAA vs CESM2-LE).

R2_time_series.R : Creates the time series of MHW statistics for coral reef regions.

R3_prediction_range.R : Plots the prediction range of MHW frequency in coral reef regions.

R4_corr_tab.R : Creates the correlation tables between dominant climate modes of seasonal to multi-year predictability of MHW statistics shown as correlation scores for selected coral reef regions identified in the CESM2-MP during 1981-2020.

Python1_Plot_MHW_figures.py : Plots the MHW figures (e.g., skill from forcing).

Python2_intrinsic_timescales.py : Calculates and plots the lag-1 autocorrelation and intrinsic timescale of monthly MHW frequency.

Python3_Composites.py : Computes and plots composite anomalies of several atmospheric forcing and ocean dynamic mechanisms associated with MHW onset using the CESM2-MP.

Python4_Hovmoeller_diagrams.py : Calculates zonal-mean temperature anomalies from 18 months to 0 preceding MHW onset at approximately near-surface, 95 m, and 198 m depths.

Python5_ElNino_composites.py : Computes ENSO composites during El Nino and La Nina for several atmospheric forcing and ocean dynamic mechanisms associated with MHW onset using the CESM2-MP.
